# T04 오늘의 진짜 정보판 — 공개 합성 fixture 꾸러미

이 폴더는 T04의 저장·장애·회복 계산을 모든 학생에게 같은 입력으로 시험하기 위한 공개 자료입니다. 자료를 받거나 실행하는 데 계정 생성·로그인·인증·초대·비밀번호·OAuth·CAPTCHA가 필요하지 않습니다.

먼저 `public-contract.json`, `criterion-registry.json`, `asset-manifest.json`을 확인하세요. 현재 정본 조건은 `T04-C01`부터 `T04-C35`까지 35개이며, 조건별로 충족 여부를 따로 판정합니다. 이 폴더의 fixture는 조건 일부를 재현하기 위한 도구이지, 제출 양식이나 완성 앱이 아닙니다.

## 구현할 제품

비개인 공개 원천에서 실제로 변하는 값 하나를 조회해 값·단위·출처·출처 시각·조회 시각·기준 시간대를 보여 주세요. 정상 응답은 `normalized-reading.schema.json`과 같은 의미로 정규화한 뒤 저장합니다.

- 같은 `signal_id + record_date`에는 새 행을 만들지 말고 원자적으로 갱신합니다.
- 다음 `Asia/Seoul` 날짜의 성공 조회는 새 일별 행을 만듭니다.
- 전일 대비는 저장한 두 값으로 다시 계산합니다.
- 실패는 정상값을 덮어쓰거나 지우지 않습니다.
- 공개 심사 화면에는 실제 개인정보나 개인 기록을 넣지 않습니다.
- 브라우저 코드·배포 파일·네트워크 응답·Git 기록·제출물에 비밀키 원문을 넣지 않습니다.

DB와 프레임워크, 무료 AI 도구는 자유롭게 고를 수 있습니다.

## 9개 결정론 fixture

`fixtures/`에는 다음 입력이 있습니다.

1. `T04-NORMAL-D1-A`: 합성 1일차 값 100, 일별 행 1개
2. `T04-NORMAL-D1-B`: 같은 합성 날짜 값 105, 같은 record ID, 일별 행 1개
3. `T04-NORMAL-D2`: 다음 합성 날짜 값 120, 일별 행 2개, 변화 절대값 15
4. `T04-TIMEOUT`: 느린 외부 응답
5. `T04-AUTH-401`: 외부 데이터 원천의 401 거절
6. `T04-RATE-429`: 외부 원천 호출 제한
7. `T04-OFFLINE`: 오프라인
8. `T04-SCHEMA-BREAK`: 응답 형식 변경
9. `T04-RECOVER-D2`: 오류 뒤 재시도 성공 — `fresh / none`, 다음 합성 날짜 행 정확히 1건 추가

`T04-AUTH-401`의 auth는 외부 원천 오류 코드입니다. 제출 앱의 로그인이나 인증을 뜻하지 않습니다. 결과물과 소스 URL은 새 시크릿 창에서 아무 인증 없이 열려야 합니다.

`adapter-reset.example.js`는 fixture의 예상 상태 전이를 보이는 CommonJS 참조 코드입니다. 그대로 복사해야 하는 라이브러리는 아닙니다. live adapter와 replay adapter가 같은 정규화·저장 함수를 호출하게 구성하면 오류 처리만 따로 꾸미는 실수를 줄일 수 있습니다.

## 재생 순서

정상·일별 저장:

1. reset
2. `T04-NORMAL-D1-A`
3. `T04-NORMAL-D1-B`
4. `T04-NORMAL-D2`

각 실패:

1. reset
2. `T04-NORMAL-D1-A`
3. `T04-NORMAL-D1-B`
4. 실패 fixture 한 개

오류 뒤 회복:

1. reset
2. `T04-NORMAL-D1-A`
3. `T04-NORMAL-D1-B`
4. `T04-TIMEOUT`
5. `T04-RECOVER-D2`

다섯 실패에서는 마지막 정상값 105와 기존 행 1건을 유지하고 `stale / 해당 error_code`를 보여야 합니다. C19의 공개 복구 상태표는 `T04-TIMEOUT` 직후 `stale / timeout`, 행 1건, 마지막 정상값 105에서 시작합니다. 다시 시도 행동을 누르고 `T04-RECOVER-D2`를 재생하면 `fresh / none`, 행 2건, 다음 합성 날짜(`2026-08-25`) 신규 행 정확히 1건, 저장값 120이 되어야 합니다.

## fixture가 대신하지 않는 것

fixture의 D1/D2는 합성 시계입니다. 다음 조건의 실제 증거를 대신하지 않습니다.

- `T04-C03`: 비개인 공개 원천의 실제 동적 값 조회
- `T04-C04~C10`: 실제 조회 화면의 값·단위·출처·두 시각·기준 시간대와 원자료·저장값·화면값 일치
- `T04-C22`: 최종 제출 꾸러미의 `제출정보.json.과정영수증[]`에 canonical kind가 `t04_day`인 영수증 정확히 2건, 두 `server_created_at`을 `Asia/Seoul`로 바꾼 날짜가 서로 다름
- `T04-C23`: 두 봉인 영수증 payload의 `source_url`·`source_observed_at`·`normalized_value`·`unit`이 앱에 보존된 같은 일별 저장값과 화면 표시값에서 일치
- `T04-C24`: 두 `normalized_value`·`unit`을 `server_created_at` 시간순으로 놓고 화면의 어제 대비 변화값을 같은 규칙으로 재계산하면 일치

채점기는 외부 API를 다시 호출해 과거 응답과 일치하는지 요구하지 않습니다. 봉인된 `t04_day` payload, 앱에 보존된 일별 저장값, 화면 표시값과 변화 재계산만 대조합니다. 학생이 별도 인증 파일이나 증거 ZIP을 손으로 만들 필요는 없습니다.

과제 제출·강사 승인·마스터 승인은 로컬 채점 결과와 분리됩니다. 마스터가 승인된 제출물을 일괄 내려받은 뒤 시간이 될 때 로컬 채점기를 돌릴 수 있습니다.
